# Добавление учебного раздела

Когда тебя просят подробно разобрать тему из файла java-backend-learning-plan.md, сохрани инфу в отдельный файл и свяжи
с основным файлом java-backend-learning-plan.md чтобы можно было кликнуть на строку.

- Не держи файлы в одной папке, структурируй их вынося в дочерние / родительские папки.
- При создание учебных файлов не дублируй информацию, которая была уже пройдена

# Стиль повествования:

Старайся использовать англицизмы только там где это действительно необходимо (Синтаксис, абривеатуры, навзвания
инструментов и библиотек). В приоретете старайся давать объяснения на русском языке

- Пример Как надо:
  "Получить Class<List<Account>> нельзя, потому что Class не хранит информацию о типе элементов списка. Поэтому
  библиотеки сериализации используют специальные объекты, например TypeReference<List<Account>>. Обычно для этого
  создаётся анонимный класс-наследник, в описании которого сохраняется List<Account>. Затем библиотека читает эту
  информацию и понимает, что элементы списка нужно преобразовывать в Account"

- Пример Как НЕ надо:
  "Но Class<List<Account>> получить нельзя. Библиотеки сериализации используют super type token — например,
  TypeReference<List<Account>> или аналог конкретной библиотеки. Anonymous subclass сохраняет generic declaration в
  metadata, откуда библиотека читает вложенный тип."

# Форматирование таблиц

Приводи таблицы к удобному читаемому виду:

- Правильно

| Java                 | Приблизительная аналогия в TypeScript/Node.js                                           |
|----------------------|-----------------------------------------------------------------------------------------|
| `.java`              | `.ts`                                                                                   |
| `javac`              | `tsc`                                                                                   |
| `.class` с байткодом | скомпилированный `.js`, но для JVM, а не текстовый JavaScript                           |
| JVM                  | среда выполнения вроде Node.js/V8, хотя архитектура и формат кода отличаются            |
| classpath            | пути, по которым runtime ищет код и зависимости; отдалённо напоминает module resolution |
| JAR                  | архив с классами и ресурсами, похожий по роли на публикуемый пакет                      |
