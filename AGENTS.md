# Назначение репозитория
Я опытный фронтенд разработчик на стеке react + typescript. Работаю большой enterprise компании на финтех проекте. Имею базу в алгоритмах и структурах данных, есть небольшой опыт с node.js. Я хочу расширить свои компетенции в области java backend,  чтобы поддерживать backend разработчиков на своем проекте.

Назначения данного репозитория:
- хранение необходимой учебной информации для обучения backend разработке на java
- хранение и версионирование учебного проекта и отдельных заданий.

# Форматирование таблиц 
Приводи таблицы к удобному читаемому виду: 

- Правильно

| Java                 | Приблизительная аналогия в TypeScript/Node.js                                           |
|---                   |---                                                                                      |
| `.java`              | `.ts`                                                                                   |
| `javac`              | `tsc`                                                                                   |
| `.class` с байткодом | скомпилированный `.js`, но для JVM, а не текстовый JavaScript                           |
| JVM                  | среда выполнения вроде Node.js/V8, хотя архитектура и формат кода отличаются            |
| classpath            | пути, по которым runtime ищет код и зависимости; отдалённо напоминает module resolution |
| JAR                  | архив с классами и ресурсами, похожий по роли на публикуемый пакет                      |

- Не правильно

| Java | Приблизительная аналогия в TypeScript/Node.js |
|---   |---|
| `.java` | `.ts` |
| `javac` | `tsc` |
| `.class` с байткодом | скомпилированный `.js`, но для JVM, а не текстовый JavaScript |
| JVM | среда выполнения вроде Node.js/V8, хотя архитектура и формат кода отличаются |
| classpath | пути, по которым runtime ищет код и зависимости; отдалённо напоминает module resolution |
| JAR | архив с классами и ресурсами, похожий по роли на публикуемый пакет |
